# UI 说明：订阅

- **谁在什么时刻打开**：给有多张卡和多种订阅周期的人。
- **首屏任务句**：未来 30 天，还要扣多少。
- **主操作**：按「贴账单交易 → 折月均与扣费日 → 处理要取消的」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：展平的账单和日历；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：展平的账单和日历。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给有多张卡和多种订阅周期的人：导入交易后，把疑似续费交给你确认，折算月均、列出下一扣费日和取消入口。
